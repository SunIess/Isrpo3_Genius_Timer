# Isrpo3_Genius_Timer
## Focus Timer — Расширение для VS Code
**Автор:** Студент 1 курса *Доткулов Инал Маратович*  
**Язык программирования:** JavaScript (Node.js)  
### 📌 Описание проекта
Расширение для редактора Visual Studio Code, техника тайм-менеджмента «Помодоро». Оно помогает концентрироваться на работе, напоминает о перерывах и ведет статистику продуктивности.

### ✨ Основные возможности
* **Гибкий запуск:** при старте таймера открывается окно, где можно ввести время сессии (по умолчанию берется из настроек).
* **Умные перерывы:** после завершения рабочей сессии таймер может сам запускать перерыв.
* **Статус-бар:** обратный отсчет отображается в нижней панели VS Code (с иконкой ⏳ для работы и ☕ (кофе) для перерыва).
* **Сбор статистики:** каждая завершенная сессия сохраняется в память расширения (`globalState`) и не пропадает после перезапуска редактора.
* **Визуализация:** команда «Показать статистику» генерирует файл с таблицей и текстовым графиком активности по дням.

### 🛠 Команды (открываются через `Ctrl+Shift+P`)
1. `Focus Timer: Запустить таймер` — запускает сессию с возможностью ввода времени.
2. `Focus Timer: Остановить таймер` — досрочная остановка (сохраняет отработанное время).
3. `Focus Timer: Показать статистику` — открывает график продуктивности.

### ⚙️ Настройки (доступны через `Ctrl+,` → Focus Timer)
* `Session Minutes` — длительность рабочей сессии (по умолчанию 25).
* `Break Minutes` — длительность перерыва (по умолчанию 5).
* `Sound Enabled` — показывать звуковое уведомление (эмодзи) по окончании.
* `Auto Start Next` — автоматически переключать таймер между работой и отдыхом.

### 🚀 Как запустить (для проверяющего)
1. Откройте папку с проектом в VS Code.
2. Нажмите клавишу **F5** (запустится окно *Extension Development Host*).
3. В новом окне используйте команды через `Ctrl+Shift+P`.
